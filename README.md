# Интеллектуальный детектор самокатов у метро 🛴

Прототип веб-приложения на базе искусственного интеллекта для автоматизированного учета и контроля плотности размещения электросамокатов около станций метрополитена. Разработано в рамках производственной практики МТУСИ.

## Стек технологий
- Python 3.12
- YOLOv8 (Ultralytics)
- Streamlit

## Как запустить локально
1. Клонировать репозиторий.
2. Создать и активировать виртуальное окружение.
3. Установить зависимости: `pip install -r requirements.txt`.
4. Скачать веса модели `best.pt` и положить их в папку по пути `./scooter_project/scooter_model/weights/`.
5. Запустить приложение: `streamlit run app.py`.
